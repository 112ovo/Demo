# 验收清单

对照设计文档《塔防 Demo（MVP）实施提示词》的验收项，逐条标注验证方式。
自动化部分用 `python -m unittest discover -s tests -v` 一次跑完；标「手动」的需要在
应用窗口里实际操作。

## 三、手动试玩检查表

1. 双击 `app\启动塔防.vbs`，等 1~2 秒出现应用窗口。
2. 点「箭塔 50」→ 鼠标移到路径旁的格子，看到半透明幽灵塔 + 射程圈 + 绿色高亮 → 左键放下。
3. 等第 1 波走过来，观察投射物命中时敌人闪白、死亡飘 `+12`。
4. 点这座塔 → 面板显示等级/伤害变化 → 升到 2 级（金币应够）。
5. 再建一座冰塔（70），观察青色脉冲圆环与敌人身上的减速环。
6. 金币不足时按钮变灰，悬停出现「金币不足」提示。
7. 点「提前开始」拿到金币奖励，连打 5 波看结算遮罩，点「重新开始」重开。
8. 关掉窗口，确认任务管理器里没有残留的 node / chrome 进程。
